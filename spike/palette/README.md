# spike/palette — інструменти вимірювання палітри й категорій (G1)

Обидва скрипти врятовані з тимчасової теки 2026-08-02: без них числа в `08` §15.11 неможливо
**відтворити**, лише переписати, а переписані числа перевіркою не є.

## `palette_check.py` — аудит палітри

Тільки стандартна бібліотека, залежностей нема.

- **CIEDE2000** — реалізацію звірено з 27 опублікованими тест-парами Sharma/Wu/Dalal (26 збіглися з
  похибкою <0,00005; 27-ма «розбіжність» виявилась помилкою в пригаданому еталоні, не в коді).
- **Симуляція дальтонізму** — дві незалежні моделі, **Viénot/Brettel 1999** і **Machado 2009**
  (severity 1.0), обидві на лінійному sRGB. ⚠️ Брати лише те, де вони **збігаються**: тритан-моделі
  відомо ненадійні й розходяться на порядок (Garasje ↔ Lager: 0,06 проти 22,01).
- **Контраст** до підложки.

```bash
PYTHONIOENCODING=utf-8 python spike/palette/palette_check.py
```

⚠️ **Вхідні умови, без яких числа не відтворюються** (їх у `08` §15.11.2 бракувало):

- контраст рахувався до **`#F4F2EF`** — типовий «папір» `topograatone`. У самому §15.11.3 правило
  сформульоване як «до **найтемнішої** ділянки підложки», а це `#DEDBD6` і подекуди `~#C2BFBA`.
  Тобто наведені числа — **оптимістичні**; за суворим правилом не проходить більше кольорів;
- заливка бралась непрозорою (`fillOpacity = 1.0`, режим «місто»). У режимі «природа» — 0,55, і
  контраст падає ще;
- POI мають **власні 7 кольорів** на тому самому екрані (три вже дублюють будівельні). Правильна
  перевірка — на **об'єднаному наборі з 19**; цього не робив ніхто.

## `category_counts.py` — гейт покриття по комунах

Рахує «усього / досяжних» по кодах `bygningstype` і скільки комун мають ≥5 досяжних у категорії.

⚠️ **Джерело даних — продакшн-`manifest.json`, якого в репозиторії немає** (вхідні GML ефемерні,
див. пам'ять `pipeline-inputs-are-ephemeral`). Скрипт читає локальну копію; шлях у ньому треба
поправити на актуальну. Копію можна взяти з R2 або з `OneDrive\Streif-device-backup\`.

Контрольні числа, які має відтворити (`08` §15.11): 129 кодів, перетинів нуль,
**226 777 усього / 196 254 досяжних** по кодах; плюс `bygningstypeUnknown` 9 679 / 8 065
= регіональні 236 456 / 204 319.
